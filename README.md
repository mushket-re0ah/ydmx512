YDMX512 is a desktop application for programming and controlling lighting equipment by DMX512.

Lighting equipment is defined as a set of fixtures that are subsequently placed within the DMX space (patched). Based on this patch, users can create scenes, control fixture parameters, and play back dynamic lighting effects.

The application is designed to work with real DMX hardware and supports synchronizing lighting sequences with temp and MIDI.

Operating DMX512 equipment requires a special controller compatible with Arduino Nano. The firmware is located in /Arduino/dmxTx/.
